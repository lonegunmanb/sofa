# Implementation Plan: Static Workers

**Branch**: `005-static-worker` | **Date**: 2026-11-26 | **Spec**: [spec.md](./spec.md)

## Summary

Implement `worker` as a golden `Valuable` block with custom decode for deferred values. Inject artifact/import context, validate nested execution controls, apply orthogonal root defaults through planner Init, unwrap the worker value namespace, and validate fallback ancestry before golden graph construction.

## Technical Context

- Go 1.27.3, golden HCL/DAG, cty.
- Pure offline unit tests only.
- Existing 002/003/004/004b values and configs are consumed directly.

## Constitution Check

All principles pass. Worker-specific semantics use golden registration, planning, preconditions, for_each, and graph traversal; only deferred-expression handling requires custom decode per frozen Stage 1 contract.

## Design

- `WorkerBlock` embeds `BaseBlock`, implements `CustomDecode`, `PlanBlock`, and `Valuable`.
- Worker EvalContext injects local `artifact()` and `import_artifact`.
- Planner Init injects missing sandbox/harness/provider traversals into fresh worker blocks.
- Planner Init validates fallback targets against a positive-reference graph that excludes fallback edges.
- `SofaConfig.EvalContext` unwraps the extra empty subtype generated by golden for `Valuable`.
- Deferred expression text is retained when permitted fields are unknown.
